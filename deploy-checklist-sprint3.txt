DEPLOY CHECKLIST - SPRINT 3 (VINData) - PRODUCCION HOSTING
==========================================================

1. Backup de la base de datos en hosting (recomendado).

2. Pull latest develop branch on hosting:
   git pull origin develop

3. Install/update PHP dependencies:
   composer install --no-dev --optimize-autoloader

4. Run migrations:
   php artisan migrate --force

5. Seed VINDATA provider and services:
   php artisan db:seed --class=ProviderSeeder --force
   OR run the SQL file seed_vindata_hosting.sql in phpMyAdmin / MySQL client.

6. Insertar/actualizar usuario admin (si no existe):
   php artisan db:seed --class=UserAdminSeeder --force
   OR run insert_admin.sql en phpMyAdmin / MySQL client.

7. Set environment variables in .env:
   VINDATA_API_URL=https://api.vindata.com/v1
   VINDATA_USERNAME=TU_USUARIO
   VINDATA_PASSWORD=TU_PASSWORD
   VINDATA_SECRET_KEY=TU_SECRET_KEY
   VINDATA_HTTP_TIMEOUT=60
   VINDATA_TOKEN_TTL_MINUTES=55

   Tambien verificar:
   PLACAS_API_URL=https://placas.info/api/v2/consultar/
   PLACAS_API_TOKEN=TU_TOKEN

8. Clear caches:
   php artisan config:clear
   php artisan cache:clear
   php artisan route:clear
   php artisan view:clear

9. Verify:
   - Login page loads con admin@vintrack.com.mx / Vintrack.2024!Admin
   - Home page shows VINData provider/services
   - Test a VIN query with VINData (requires real credentials and credits)

NOTA: En local ahora phpunit.xml usa SQLite :memory: para no borrar la BD MySQL al correr tests.
