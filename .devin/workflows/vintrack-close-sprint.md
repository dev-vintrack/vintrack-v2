# VINTrack — Close Sprint

Preconditions:
- implementation complete;
- validation report exists;
- tests documented;
- Owner explicitly approved.

Then:
1. Mark Sprint result APPROVED.
2. Update `docs/PROJECT_STATE.md`.
3. Record relevant decisions in `docs/DECISION_LOG.md`.
4. Record approved changes in `docs/CHANGE_REQUESTS.md` where applicable.
5. Identify the next Sprint.
6. Do not start the next Sprint automatically.

Approval is a governance event and cannot be inferred from silence.
