- `docs/BUSINESS_RULES.md`
- Sprint specification.

Run applicable automated and regression tests. Check authorization, migrations, cross-engine compatibility, file security and auditability as applicable.

- completed scope;
- incomplete scope;
- files changed;
- database changes;
- tests;
- failures;
- known issues;
- risks;
- manual validation;
- production impact;
- rollback considerations;
- recommendation: APPROVE / REJECT / NEEDS CHANGES.

Never claim Owner approval.
