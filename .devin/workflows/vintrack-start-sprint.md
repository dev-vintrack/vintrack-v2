# VINTrack — Start Sprint

Before planning or modifying code, read:
1. `docs/VINTRACK_MASTER_SPEC.md`
2. `docs/PROJECT_STATE.md`
3. `docs/DECISION_LOG.md`
4. `docs/CHANGE_REQUESTS.md`
5. The requested Sprint specification.

If the previous Sprint has a result file, read it.

Rules:
- Do not assume approval.
- Do not implement future Sprint scope.
- Do not modify production.
- Do not recreate `consultations.provider_services_id`.
- Do not use `vehicles` as notification-expedient master.
- Inspect actual code/database first.
- Stop and report contradictions.

Before coding, present:
- current state;
- previous Sprint status;
- requested scope;
- files/components likely to change;
- database objects likely to change;
- risks;
- tests;
- deployment implications.

Wait for Owner authorization when required.
